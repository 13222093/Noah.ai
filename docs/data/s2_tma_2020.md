# S2 archive `tma_2020.xlsx.csv`: findings and import (B-041)

File: `ml-service/data/tma_2020.xlsx.csv`, 31,059 rows covering 21 posts from 2019-12-23 (one stray Cibalok row) to 2020-01-31. Columns: `nama_pintu_air, lokasi, latitude, longitude, tanggal, tinggi_air, status_siaga`.

## Units: `tinggi_air` is mm at 1 cm resolution
- Every value is a multiple of 10.
- Manggarai ranges from 4870 to 9690, which is 487 to 969 cm and plausible. In cm it would be 48 to 97 m, which is not plausible.
- At Manggarai, the `status_siaga` labels change at 7480 (Normal) / 7500 (Siaga 3), 8450 / 8510 (Siaga 2) and 9460 / 9520 (Siaga 1). These brackets contain the official 750 / 850 / 950 cm, and only those values.
- The live S1 page (connector fixture of 2026-11-02) publishes its raw field in mm. Manggarai shows 5340 raw next to 534 cm in the table, and its raw Siaga values are 9500 / 8500 / 7500.
- `DATASET_FINAL_TRAINING.csv` has Manggarai at 55.15 to 96.75, which is the same series in dm (mm / 100).

The importer converts the values to cm with `noah.timeunits.length_to_cm(v, "mm")`.

## Time
`tanggal` is naive local time. The importer reads it as WIB (UTC+7) and stores it in UTC. This still needs DSDA confirmation (audit Q11).

## Structure and duplicates
Every post has exactly 1,479 rows. The file is a series of snapshots of the Posko Banjir table, and a post that did not update repeats its last reading. 8,947 rows exactly repeat an earlier (post, timestamp, value). No timestamp has two different values. The importer emits one observation per (post, timestamp), which matches the database key `observations (station_id, ts)`, and counts the repeats. The raw file in object storage keeps every copy.

## Quality flags (flag, never drop)
- `negative_level`: 514 observations after dedupe: Cideng 481, Cibalok 32 and Pulo Gadung 1. Pluit is exempt (`allows_negative`): its reservoir is normally below gauge zero, and DSDA's own Siaga 3 there is -50 cm.
- `isolated_spike`: 20 observations that are at least 100 cm away from both neighbours, where the neighbours agree and lie within 180 min of each other. They are at Angke Hulu (9), Kali Duri (5), Karet (2), Hek, Pesanggrahan, Pluit and Pulo Gadung. Examples: Karet 280 → 0 → 280 cm, Pulo Gadung 334 → -1 → 334 cm. One reading is both negative and a spike (Pulo Gadung -1 cm), so there are 533 suspect observations in total. The rule only catches single readings. Dips that last two readings or more, such as Manggarai at 487 cm on 2020-01-28 and Pasar Ikan at 20 cm for a day, are not flagged and are left for a later QC rule.

## Import counts (full file)
31,059 rows read, 0 unparsed, 22,112 observations (21,579 ok, 533 suspect), 8,947 repeats. Running the import a second time writes 0 rows. This was checked against a scratch PostgreSQL 16 database.

```
python -m noah.importers.s2_tma_2020 --dry-run             # parse and count, write nothing
python -m noah.importers.s2_tma_2020 --derive-thresholds   # Siaga evidence per post (JSON)
python -m noah.importers.s2_tma_2020                       # write via PostgresSink (NOAH_DATABASE_URL, object store env)
```

The raw payload key is fixed: `raw/s2_opendata/2026/03/01/20260301T103058Z_3ceafa8a4130.csv`. The file has no download time, so `fetched_at` is set to the time of the commit that added it.

## Siaga evidence
`derive_siaga_thresholds` reports a threshold only when the labels at a post never overlap, the level and the level below it were both observed, and the bracket is no more than 10 cm wide and contains exactly one multiple of 10 cm. Applied to Manggarai, the rule gives exactly 750 / 850 / 950. The results are stored as `evidence.s2_2020` in `config/stations.yaml`. They agree with the 2026 S1 page at 13 posts and differ at Cibalok (Siaga 3) and Jembatan Merah (Siaga 2 and 1), so thresholds have changed since 2020.
