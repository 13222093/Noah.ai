### Top 10 decisions
1. **Rotate and purge the three committed secrets (G-001 to G-005).** The Supabase service_role JWT is live, unrotated and in a public repo, and it bypasses all RLS. The Roboflow key is the active runtime value. An OpenWeatherMap key sits in history.
2. **DELETE the Twilio citizen SMS pipeline and the smart-alert chain (G-008, G-009).** Today anyone can `POST /api/sms-alert` and send "Segera evakuasi!" to every subscriber, with no auth and no rate limit. This is a G1 breach, and it stays inert only while `TWILIO_*` env vars are empty.
3. **Lock down, then purge, citizen PII (G-010, G-011).** The public anon key can read every subscriber phone number and message log. `/api/flood-reports` uses the service role to return reporter names and contacts to anyone (G3).
4. **REBUILD water level as a polite S1 connector (G-037, D1).** Today's "LIVE" Manggarai value is a January 2020 CSV, indexed by the server clock and stamped `now()`. It is also in decimetres labelled as cm, so every "cm" figure is 10 times too low.
5. **DELETE the whole forecast core (G-071 to G-075, D2 to D4).** The LSTM is mis-wired (wrong feature order, wrong units, wrong sequence length). The "physics engine" is an uncalibrated formula. GOD MODE and `scenario_demo` return canned CRITICAL results, and `scenario_demo` needs no secret at all.
6. **Remove every fake data path, and allow synthetic data only behind `NOAH_DEMO_MODE` with a SIMULASI label (G-021 to G-036, G-113).** The default landing page shows `Math.random()` posts and pumps labelled "LIVE". Shelters show a random "verified by BPBD/BNPB".
7. **NEW append-only target schema on PostGIS (G-057, G-060 to G-067).** No existing table maps to `03`. Migration 001 cannot apply. Five tables have no migration at all.
8. **NEW OIDC auth with roles and RLS (G-069).** Every page and route is public. W1 adds a deny-by-default gate, and full roles follow in W3.
9. **REBUILD tests and make CI run them, together with gitleaks and guardrail lint (G-111 to G-113).** CI runs `tsc` and `build` only. 3 test cases run locally, and there are 0 Python tests.
10. **Build in plan order, M1 first, and reuse the shells (G-080 onward, G-095, G-117, G-119).** Order: M1 scoreboard (W2), then the M2 baseline and M3 simulator (W3). Reuse the Next.js map and tiling shell, shadcn, i18n, Sentry and the FastAPI skeleton. Nothing carries over from the forecast core or the public features.
