# Repo audit (repo-auditor), Phase A

Audit date: 2026-11-02. Branch `main` at `49a23e3`. Read-only audit; no application code was changed. Line numbers were checked against the working tree on that date.

Secret values are not reproduced anywhere in this file. They are cited by file:line and kind only.

## 1. Summary

### Repository at a glance
- **Size:** 381 tracked files, 46 commits. Hand-written source is about 39k lines (TS/TSX/Python/SQL/CSS). Data/model artifacts in git: `ml-service/data/*.csv` (~3.4 MB), `ml-service/models/*` (~13.8 MB, including two identical 6.5 MB YOLO weights).
- **Stack:** Next.js 16 (App Router) + React 18.2, Tailwind 3.3, shadcn/Radix (`components/ui/`, 31 files), react-leaflet 4, TanStack Query, zustand, Sentry 10, `@ducanh2912/next-pwa`, Upstash Redis, Supabase JS, Gemini SDK, Twilio SDK.
- **Services:**
  1. Next.js app: 23 `page.tsx` and 32 `route.ts` under `app/`.
  2. FastAPI ML service: `ml-service/src/main.py`, TensorFlow LSTM plus the Roboflow HTTP API.
  3. Supabase project: 5 migrations and `supabase/seed.sql`.
- **Entry points:**
  - `app/page.tsx` redirects to `/dashboard`.
  - `next.config.js:16-23` rewrites `/` to `public/landing.html`.
  - `ml-service/Dockerfile` runs `uvicorn src.main:app`.
  - `docker-compose.yml` runs the `nextjs` and `ml-service` containers, with port 8000 published.
  - `vercel.json` rewrites `/about` and `/contact` to static HTML.
- **CI:** `.github/workflows/ci.yml` runs `npm ci`, `tsc --noEmit` and `next build`. It runs no tests, no lint, no Python checks and no secret scan.
- **Auth:** there is none. There is no `middleware.ts` or `proxy.ts`. Every page and API route is public. The only gate in the whole repo is the ML `/admin/set-demo-mode` secret, and it is read from the JSON body.
- **Remotes:** `origin` and `fork` both point to GitHub repos under `13222093`. Any secret in history should be treated as exposed.

### Top 10 decisions
1. **RA-052/RA-053 (D10, D11) Rotate the Supabase service_role JWT and the Roboflow key.** Both are committed, the service_role key is identical to the one in local `.env.local`, and the repo has GitHub remotes.
2. **RA-039 DELETE the Twilio citizen SMS pipeline.** An unauthenticated `POST /api/smart-alert` can chain into an "EVAKUASI SEGERA" SMS to every public subscriber, which breaks Guardrail 1.
3. **RA-017 REBUILD water level (D1).** The current data is a January 2020 CSV replayed on the wall clock and stamped `now()`. It feeds `/api/predict`, the map prediction layer and the chatbot.
4. **RA-021/RA-022/RA-023 DELETE the LSTM, the "physics engine" and GOD MODE (D2-D4).** None of them is a forecast. GOD MODE is a global, process-wide switch.
5. **RA-029 REBUILD the dashboard (D5).** Every number on the default landing page comes from `Math.random()` through `lib/mock-data.ts`.
6. **RA-014 NEW auth and roles layer.** None exists today. Every page and API route is public, including routes that write with the service role.
7. **RA-015 REBUILD the database schema.** None of the 8 migrated tables maps to the `03` data model, 4 tables in use have no migration, and nothing is append-only.
8. **RA-002/RA-031 REFACTOR the Leaflet map and tiling shell into the Ringkasan page.** Strip the mock, weather and AQI layers first.
9. **RA-007/RA-008 REBUILD the tests and make CI run them.** CI currently runs 3 real tests, and the smoke test does not even match the vitest include pattern.
10. **RA-061 to RA-066 NEW work.** The connectors, M1, M2, M3, recommendations and the WhatsApp notifier do not exist.

- **G6 (append-only):** no table is append-only. `app/api/preferences/route.ts:67` updates rows. The SMS and incident tables have `updated_at` columns.
- **G7 (provenance):** replayed values are re-stamped with `new Date()` (`app/api/water-level/route.ts:74,92`). Mock timestamps are random (`lib/mock-data.ts:42`).
- **G8 (units and time):** `Asia/Jakarta` does not appear anywhere in the repo. Server-local `getHours()` drives the replay. The mock water level is in **m** with Siaga labels (`lib/mock-data.ts:30-41`).
- **G9 (honest metrics):** `ml-service/models/training_results.json:19,32` reports R2 and accuracy. `ml-service/src/metrics.py:41,61-81` computes them.
- **G10 (secrets):** D10, D11, no secret scanning in CI, and `supabase/.temp/` is committed. Several third-party keys are exposed to the browser through `NEXT_PUBLIC_OPENWEATHER*`.
- **G11 (tests in CI):** D9.
- **G13 (licensing):**
  - `ml-service/models/yolov8n.pt` and `yolo_model.pt` are Ultralytics weights, which are AGPL-3.0.
  - `ml-service/src/yolo_model.py:21` optionally imports `ultralytics`.
  - No dependency license record exists.
- **G14 (budget):** Twilio, Gemini, OpenWeatherMap, Roboflow, Upstash and WAQI are wired in. None of them is in the RAB, which names Anthropic as the only LLM.
