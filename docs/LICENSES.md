# Dependency licences

Guardrail 13: core code must be under a licence compatible with government use. GPL code (for example GNN-UDS, MARL-UDS) lives only in a separate research service and is never linked into the core. This record covers B-026 / G-107.

- Project licence: Apache-2.0 (`LICENSE`). Contributor consent is open (Ari Q18, G-108).
- How it is enforced:
  - `node scripts/check-licenses.mjs` runs in CI and fails on GPL, AGPL or SSPL in runtime npm packages.
  - `pip-licenses --fail-on` runs in CI over `ml-service` requirements.
  - CI publishes CycloneDX SBOMs (`sbom-web.cdx.json`, `sbom-ml.cdx.json`) as build artifacts.
  - `scripts/check-guardrails.mjs` bans `ultralytics` (AGPL) imports and requirements.
- How to regenerate the npm section: `node scripts/check-licenses.mjs --write`.
